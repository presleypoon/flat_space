# Flat Space

In this folder, there are 2 folders in it, they are the same code but one has merge and one hasn't in the future we might combine them but until then, we have them seperately.

## How to run

You need to have [cargo](https://rust-lang.org/tools/install/) installed to run this.
To run them, go to the folder and double click `build.bat` and it will compile and run.  
If you are running a non-window enviroment, you need to get the terminal open and run `cargo run --release` in that folder

## Keybinds

`esc` to quit the program  
Left click to spawn particle

## Bugs

If you think there are some things that should not happen, report them on [Flat Space](https://github.com/presleypoon/flat_space)
